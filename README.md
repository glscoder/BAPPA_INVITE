# 🌺 Ganesh Chaturthi Digital Invitation Card 🪔

A premium, mobile-first, cinematic digital invitation website for Ganesh Utsav celebrations. Designed to feel like receiving a handcrafted royal temple invitation rather than a generic webpage.

---

## ✨ Features

- **📱 9:16 Mobile-First Architecture:** Crafted specifically for smartphone screens with zero horizontal overflow, silky scroll-snap page transitions, and an elegant desktop luxury card frame.
- **🚪 Cinematic 3D Temple Doors Reveal:** Majestic temple doors that part with realistic 3D perspective upon tapping the central royal seal.
- **🪔 Sacred Audio Engine:** Built-in Web Audio Tanpura drone, calming Bansuri (flute) melodies, and resonant temple bell strikes with a dedicated floating brass bell mute/unmute controller. Zero external audio downloads needed.
- **🌸 Ambient Canvas Petals & Stardust:** GPU-accelerated 60fps canvas particles of marigold flower petals and glowing golden dust.
- **🕉️ Respectful Minimalist Vector Art:** Bespoke gold-foil line-art of Lord Ganesha, auspicious Kalash, sacred Diyas with flickering flames, and Modaks.
- **🗺️ Interactive Map Navigation:** One-tap "Get Directions" button linking directly to Google Maps coordinates.
- **📅 Add to Calendar:** Instant synchronization with Google Calendar and downloadable `.ics` for Apple & Outlook calendars.
- **💬 One-Tap WhatsApp Share:** Pre-composed festive invitation message with link unfurling and high-resolution Open Graph preview card.
- **🙏 Guest RSVP Modal:** Interactive attendance confirmation with localStorage persistence and festive blessing acknowledgement.

2. **Dates & Timings:**
   - Search for `Utsav Schedule` (Line 131) to adjust Sthapana, Aarti, Prasad, and Visarjan timings.
3. **Venue & Address:**
   - Search for `Shree Ganesh Kripa` (Line 185) to change address and update the Google Maps query in the `href` attribute.
4. **Phone / WhatsApp Number:**
   - Search for `+91 98765 43210` (Line 230) to update your contact phone number.

## 🚀 How to Run Locally

You can preview the invitation using any local static web server:

```powershell
# Using Python
python -m http.server 3000

# Or using npx serve
npx -y serve .
```

Then open `http://localhost:3000` in your web browser.
